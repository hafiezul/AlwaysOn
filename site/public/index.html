Why AlwaysOn

Your status turns yellow when the Mac sits idle. AlwaysOn sends a small input every 45 seconds, so it stays green while you get coffee.

The app

Runs from
the menu bar

AlwaysOn has no Dock icon and no window to keep open. The menu shows the time left in a session and a strip of recent inputs.

Sends input every 45 seconds by default. With adaptive pacing, it waits until you've been idle for 1, 2, or 4 minutes.

45s

Pauses while the Mac sleeps, locks, or switches users, then sends an input as soon as you're back.

How it works

Many workplace apps set your status from the Mac's idle time. Each input from AlwaysOn resets that time to zero.

MouseEvent

Sends a mouse event at the pointer's current position. The pointer doesn't move.

ShiftKey

shift

Presses and releases Shift. While another app plays video, AlwaysOn sends Shift instead of mouse input, so the player doesn't show its controls.

You can also alternate between the two. With adaptive pacing, AlwaysOn sends nothing while you're typing.

Works with

Turn on target apps, and AlwaysOn sends input only while one of them is running.

Features

Starts and stops
on its own

01

Adaptive pacing

Sends input only after the Mac has been idle for 1, 2, or 4 minutes. While you type, it sends nothing and wakes about once every couple of minutes.

02

Work hours

Set hours for each day, a daily break, and days off. Sessions start and stop on that schedule.

MTWTFSS
03

Profiles

Each profile has its own pacing, target apps, sleep prevention, and safety stops. AlwaysOn can switch profiles when you join a Wi-Fi network.

OfficeHomeCafe
04

Keep online until

Keep online until a set time, until a calendar event ends, or while a macOS Focus is on.

17:30
05

Saves energy

Pauses while the Mac sleeps or the screen is locked. In Low Power Mode, or when the Mac runs hot, it doubles the interval, up to 2 minutes.

06

Safety stops

Stops on its own after you've been away too long or when the battery runs low.

Command line

Stay online
while it runs

alwayson run keeps you online while a command runs and ends the session when the command exits. Output goes straight to your terminal, and the helper exits with the command's exit status.

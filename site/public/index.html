AlwaysOn is a menu bar app for macOS that keeps you shown as active in Teams, Slack, Zoom, and other workplace apps. Every 45 seconds it moves the cursor one pixel and back, or taps Shift.

Download for macOS Read every line on GitHub

Free and open source. Needs macOS 13 or later.

What it does

  • Waits until you've been idle, and skips input while you're using the Mac
  • Pauses while the Mac sleeps or locks, and backs off in Low Power Mode
  • Keeps you online until a time or a calendar event, or while a command runs
  • Work hours with per-day times, a daily break, and days off
  • Focus filters and Wi-Fi networks that switch profiles
  • Safety stops when you're away too long or the battery runs low

Go get the coffee

  1. Download it and drag it to Applications. Open the DMG and drag AlwaysOn.app into Applications.
  2. Open it once. If macOS says it couldn't verify the app, go to System Settings > Privacy & Security and click Open Anyway.
  3. Allow Accessibility. Notifications, Location, and Calendar are optional.
  4. Start a session. Click the icon in the menu bar, or press ⌥⌘K.
  • Doesn't collect data
  • Signed updates from GitHub Releases
  • Accessibility access carries over between updates
